## Configuration and policy

`compat.modularGolemsCompatEnabled` and `compat.quarkToretoiseCompatEnabled` default to `true` in server `config/magnetization-common.toml`. They are runtime controls: normal NeoForge config reload applies them, with classification refreshed on the following server tick. Item/material tag changes need a data reload. No classification is permanently cached by shared entity type.

The existing Reborn 21.1.0.1 allowlist and adapter remain unchanged. All three adapters join the same intrinsic-response decision: an explicit `#magnetization:magnetizable` entity tag and a material match still count only once. Disabling a material adapter does not disable explicit type tags, worn magnetic equipment, status effects, or other independent responses. The administrative `#magnetizing:unmoveable_by_magnets` veto retains priority. Unknown/nonmetal materials grant no automatic body response.

## Aircraft reproduction and test limits

The before-fix low-force airship trace fails after polarity reversal: its server velocity accumulates separately from native pilot simulation, so absolute velocity packets keep driving the client toward the emitter. At the same low force the repaired airship passes, as do eight further vehicles; a Fokker’s native motion prevented a net reversal in that weak fixture. The final all-vehicle run uses a controlled 9 N field override at three blocks (rather than nominal tier strength) so both directions are observable within each 180-tick run. The analyzer requires server completion and at least eight real pilot and observer samples per vehicle, with motion in both directions. It does not use mocked network recipients.

Remaining boundaries: aircraft crafting, survival fuel consumption and variable-latency stress; every Sophisticated Storage upgrade’s production behavior and process restart (the tested persistence is a closed/reopened Sable disk round trip); complete cannon/pulley/machine production workflows beyond retained state and the explicitly exercised native interactions. Raw Gravitite floating is intentional upstream behavior. These limits are not advertised as verified compatibility. A new active-field adapter for Create: Magnetics remains separate proposed work; its existing crash option only works around the upstream dedicated-server sound-class failure.
