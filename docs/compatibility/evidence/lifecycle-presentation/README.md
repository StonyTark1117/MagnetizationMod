# Native lifecycle and rendered presentation evidence

Captured 2026-10-01 on the refreshed development pins. Five server/client pairs passed; all 86 screenshots are original client captures. `results.json` records native assertions, full-log hashes, source hashes, runtime JAR hashes and evidence-file hashes. `release-checks.json` records 255 passing unit tests, 173 passing core GameTests, release checks and minimal client startup.

Rendered review covered all 37 addon menu selections, eight powered states, and first/final captures of all 18 Ponder scenes. The native menu inventory in `track-style-menu.json` matches the fixture. Steel and white styles show independent purple supports and cream rails; wood variants retain their palettes. Supports show size and shape changes; invisible hides the curve between anchors. MAGNET and BRAKE center beams visibly change under field transitions. The corrected gas scenes display their described markers.
