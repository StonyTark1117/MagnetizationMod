# Magnetization 1.4.7

For Minecraft 1.21.1 and NeoForge. Install on both client and server with the same required dependencies as 1.4.6.

This update adds one client-only setting: **Goggles Shift Inspection** (`visuals.gogglesShiftInspectionEnabled`). It is enabled by default, preserving the 1.4.6 experience. Set it to `false` in `config/magnetization-client.toml` or under Mods → Magnetization → Config → Visual Effects to disable the sneak-held magnetic ship inspection panel, its force arrows, and its inspection requests. Other goggles information and magnetic shaft visualization remain available.

See the [configuration reference](https://github.com/StonyTark1117/MagnetizationMod/blob/v1.4.7/docs/configuration.md) and [full changelog](https://github.com/StonyTark1117/MagnetizationMod/blob/v1.4.7/CHANGELOG.md).
